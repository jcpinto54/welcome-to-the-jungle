# The opening scream

Drop a file named `welcome.mp3` in this folder and the game plays it when you enter the jungle ("WELCOME TO THE JUNGLE"). Without it, the game uses a text-to-speech stand-in with the same timing.

The famous Axl Rose scream is a Guns N' Roses master recording. Using it in a public build needs a licence for the recording and the song. A sound-alike recorded by someone on the team works with no licence.
